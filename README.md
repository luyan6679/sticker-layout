# Paper Labs · 排版工作台 V1.9

一个纯静态、无账号、无需后端的照片贴纸排版工具。以 V1.8 为基础持续升级，保留原有配色及全部主要能力。

## 本次更新

- 标题更改为「排版工作台」，保留鼠尾草绿、奶油白视觉语言。
- 常见纸张：A3 / A4 / A5 / A6 / ISO B5 / 5 寸 / 6 寸 / 7 寸 / 8 寸相纸，以及自定义宽高。
- 修改纸张、方向、页边距和间距会自动重新排版，**不改变贴纸原本的实际尺寸与数量**。
- 预览区改为所有纸页从上往下连续显示，内嵌独立滚动；桌面素材列表和设置区也独立滚动。
- 预览选中某张照片，桌面左侧素材列表自动内部滚动并高亮；手机端显示轻量素材提示，不强制切换页面。
- 支持 Ctrl/⌘ 追加、Shift 跨页连续选中；手机点击「多选模式」后可多选。
- 「删除选中」按单个 **贴纸副本** 删除；左侧卡片 × 删除 **整张素材及其全部副本**。删除后自动补位并重新分页，支持撤销（Ctrl/⌘+Z）。
- 只渲染接近可视区域的纸页，适应大批量图片；PDF/打印时仍根据完整页面数据导出全部纸页。
- PDF 使用实际选择的纸张毫米尺寸；保留 V1.8 的直接生成下载与独立打印。
- 旧版 `.stickerproj` 文件可以继续导入，缺少新字段时按 A4 恢复。

## 源代码结构

```
index.html              页面结构及操作面板
styles.css              视觉样式、桌面/手机响应式布局
app.js                  主控制器：图片导入、项目保存、事件绑定
modules/paper.js        纸张规格与尺寸管理（纯函数）
modules/layout.js       排版计算、展开副本、按副本删除（纯函数）
modules/preview.js      预览页 DOM 生成、按需渲染辅助
modules/pdf.js          浏览器内原生 PDF 生成，不依赖 CDN
README.md               说明文档
DEPLOY.md               部署及升级说明
tests/layout.test.mjs    纸张、重新排版与删除单元测试
```

模块用浏览器原生 ES Modules，不用 React/Vue/打包器，不依赖 npm 运行环境。**`app.js` 是原有事件/UI 控制器，后续可继续拆分，但不影响已有项目数据。**

## 使用提示

1. 导入相片，同一张图自动跳过重复；想印多份请改素材「数量」。
2. 点击预览区「纸张」按钮可快速切换 6 寸相纸等尺寸。
3. 纸页可在预览窗口内部连续向下滚动，左侧素材与右侧设置不会随之移动。
4. 选中贴纸后可批量删除、加减数量或调整尺寸。批量尺寸仍按 **源素材** 应用，同一素材的其他副本也会一起变更尺寸。
5. 导出 PDF 时，若有贴纸过大，界面会提示原因，用户可以手动选择「自动缩小超出项」；不会暗中忽略素材。
6. 使用真实打印机时请设置「实际大小 / 100%」，并检查装纸规格与网站一致。

## 本地使用与测试

本项目使用原生 ES Modules，直接双击本地 `index.html` 在部分浏览器可能因文件协议限制而无法载入模块。请在项目目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

运行纯计算逻辑测试（需要 Node.js）：

```bash
node tests/layout.test.mjs
```

## 兼容说明

原 V1.8 项目数据和 PNG/JPG/WEBP 导入流程保持兼容。旧项目文件中的 `paper` 字段若为空或为 A4，直接使用 A4；新加入的 `customPaperWidth` / `customPaperHeight` 缺失时分别按 210 / 297 mm 恢复。

本地保存项目仅存在当前浏览器 IndexedDB 中；换浏览器或清理浏览数据前，建议单独「导出项目文件」备份。Android 厂商自带浏览器的批量图片选择是否支持多选，仍需真机验证。部分打印机或照片冲印店提供的“6寸”精确规格可能与标称的 102 × 152 mm 略有不同，此时请使用自定义纸张。
