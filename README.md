# A4 贴纸排版器 V1.6

V1.6 在 V1.5 的全部排版、打印、项目保存和手机适配功能基础上，重点更新了两部分：手机相册批量选择，以及统一的视觉设计语言。

## 1. 手机端批量选择照片

- 图片选择器改为 `accept="image/*"` + `multiple`，优先调用系统原生图片选择器。
- 手机浏览器支持多选时，可在系统相册 / 文件选择器中一次勾选多张照片。
- 若某个手机浏览器自身只提供单选，也可以重复点击“添加图片”；已有图片不会被清空。
- 导入期间会显示“正在导入 N / 总数”，大量图片时更容易确认当前进度。

> 是否能在系统相册界面中一次选择多张，最终仍由手机系统和浏览器的文件选择器能力决定；网页已经按标准多选方式请求。

## 2. 新视觉设计

设计语言参考了用户提供的移动 App：

- 低饱和鼠尾草绿作为顶部主色。
- 暖奶油色作为页面底色。
- 深森林绿用于主按钮和手机底部导航。
- 白色大圆角卡片承载功能区，减少硬边框。
- 主要圆角 22–30px，搭配轻柔阴影。
- 字体使用系统 SF Pro / Inter / PingFang SC 字体栈。
- 手机标题约 28px，分区标题 17–19px，正文 12–13px，辅助标签 10–11px。
- 手机底部导航改为悬浮深绿胶囊式结构。
- 桌面端与手机端共用同一套颜色、圆角、字体和组件规则。

## 保留功能

- A4 横向 / 纵向自动排版
- 自动多页
- 原比例缩放
- 单张尺寸和数量设置
- 预览区多选与批量尺寸
- 30 / 40 / 50 / 60 / 70 mm 快捷长边
- ±10% 批量缩放
- 点击预览定位素材
- 保存 / 恢复 / 导入 / 导出项目
- 打印 / 保存 PDF
- 手机素材 / 预览 / 设置三页签
- 手机预览多选模式
