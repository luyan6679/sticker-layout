# 排版工作台 V2.1｜超密集排版

本版基于 V2.0 画布优先工作台，仅增加新的排版策略及其打印/预览支持。保留原有 UI、图片导入、项目文件、批量编辑、纸张和 PDF 功能。

## 新增：超密集排版（见缝插针）

在 **设置 → 自动排列方式** 中选择 **超密集排版 · 见缝插针**：

- 不局限于逐行排版，会搜索当前页所有空白矩形，并从尚未放入的照片中寻找合适的图片填充。
- 采用独立的 `modules/dense-layout.js`（MaxRects 多策略装箱）；对 4 种启发式策略的结果比较，优先减少页数、提高先前纸张的利用率。
- **允许贴纸自动旋转 90°**（可取消勾选）：只改变纸上摆放方向，不改变真实宽高面积、不拉伸原图；预览、打印、PDF 输出方向一致。
- 严格尊重页边距、贴纸间距和原有副本数量；删除之后会自动重新装箱补位。
- 每页预览显示有效区利用率（只统计贴纸面积，不统计贴纸间距及页边距）。
- `紧凑排列` 和 `按上传顺序` 模式均保留，不改变既有项目的模式设置。旧 `.stickerproj` 项目继续兼容。

**算法说明**：混合尺寸二维装箱属于 NP-hard 问题，超密集排版是多启发式近似优化，不能对所有组合保证全局最大填充率。旋转可能改变照片阅读方向，可在设置中关闭。

## V2.0 既有界面（原样保留）

- **画布占据主屏幕**：手机顶部缩为约 48px，画布覆盖剩余视口（在 390×844 的测试视口中约占 94.3%）。页面始终只滚动纸张预览，不滚动整个站点。
- **悬浮工具坞**：添加、素材、多选、设置、导出五个操作以窄幅悬浮工具栏出现；不会挤占画布布局。
- **素材与设置抽屉**：桌面侧滑、手机底部弹出；内部独立滚动，不重排/压缩中间纸张。
- **选中后再编辑**：画布显示紧凑“已选 X 张”提示，点击后弹出批量编辑面板（数量、尺寸、缩放、删除），常态不占用空间。
- **统一弹窗**：纸张选择、导出中心、编辑面板采用统一圆角、间距与遮罩，关闭后自动返回编辑区域。
- **导入反馈**：从画布导入照片后，会直接显示导入数量与重复跳过数量，避免提示藏在素材抽屉中。
- **标题**：排版工作台。

## 保留的功能

- 图片批量导入、安卓兼容选图（受设备选择器能力限制）；图片内容去重；同图多个副本通过数量控制。
- 保持原图比例、默认尺寸/预设、选中多个贴纸批量修改尺寸与数量。
- 删除单个贴纸副本、素材整体删除、删除后自动补位、撤销。
- A3/A4/A5/A6/B5、5/6/7/8 寸相纸、自定义尺寸、横向纵向、页边距和贴纸间距；多页连续预览。
- 按真实毫米尺寸直接生成 PDF；打印功能单独保留。
- 保存/恢复浏览器本地项目，导入/导出 `.stickerproj`，继续兼容旧项目。

## 代码结构

```text
index.html                页面结构、现有操作控件
styles.css                原有基础组件样式（兼容保留）
css/canvas-shell.css      V2.0/V2.1 画布与响应式布局、抽屉及浮层
app.js                    状态、导入、选择、项目保存等业务协调
modules/paper.js          纸张规格与尺寸计算
modules/layout.js         三种排版模式调度、补位、删除逻辑
modules/dense-layout.js   超密集 MaxRects 二维装箱算法
modules/preview.js        连续预览渲染和素材滚动定位
modules/pdf.js            PDF 文件生成
modules/shell.js          V2.0/V2.1 工作台弹层、抽屉及快捷操作
```

保留原有模块文件名与核心函数，新增界面模块 `modules/shell.js`；以后可直接迭代 UI，而无需修改 PDF/布局算法。

## 本地打开

由于项目采用 ES modules，建议在当前文件夹通过静态 HTTP 服务访问，而不是双击 `index.html`：

```bash
python -m http.server 8000
```

随后打开 `http://localhost:8000/`。线上可直接用 GitHub → Vercel 静态部署，不需要后端或构建命令。
