# Sticker Layout / A4 贴纸自动排版器

一个纯前端、本地处理图片的 A4 贴纸自动排版工具。

## 当前版本

V1.5 手机适配版

## 主要功能

- 批量导入图片
- 保持原图比例缩放
- A4 自动分页
- 横向 / 纵向纸张
- 页边距与贴纸间距
- 单张尺寸调整
- 批量多选调整尺寸
- 30 / 40 / 50 / 60 / 70 mm 快捷长边
- ±10% 批量缩放
- 点击预览定位对应素材
- 项目保存、导入、导出
- 打印 / 保存 PDF
- 手机端素材 / 预览 / 设置三页签适配
- 手机端多选模式
- 大量图片导入与分页预览优化

## 隐私

图片默认只在浏览器本地处理，不会自动上传到服务器。

## 本地运行

直接双击 `index.html` 即可。

也可以使用任意静态 HTTP 服务器，例如：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## Cloudflare Pages 部署

本项目是纯静态站点，不需要构建步骤。

推荐设置：

- Framework preset: `None`
- Production branch: `main`
- Build command: 留空
- Build output directory: 仓库根目录

部署后即可通过 `*.pages.dev` 地址访问。
