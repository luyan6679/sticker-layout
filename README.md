# A4 贴纸排版器 V1.7

V1.7 在 V1.6 的视觉设计、手机布局、批量尺寸、项目保存与打印功能基础上，重点增强 Android 厂商浏览器的选图兼容性，并加入重复照片检测。

## Android 批量选图兼容

手机素材页现在保留两个入口：

- **添加图片**：继续调用系统相册，浏览器支持多选时可以一次勾选多张。
- **批量选图（兼容）**：优先尝试支持 `multiple` 的现代文件选择 API；不支持时回退到 Android 系统文件 / 文档选择器。
- 即使设备最终仍只允许单选，也可以重复添加，已有素材不会被清空。

> Android 的最终多选界面仍由手机系统和浏览器决定，因此网页不能强制所有厂商相册进入多选模式；V1.7 提供了额外兼容入口和回退路径。

## 重复照片自动检测

- 新导入照片会计算内容指纹。
- 同一文件重复选择时自动跳过。
- 同一照片改名后再次选择，会再通过缩略图内容指纹二次判断。
- 导入完成后显示“已导入 / 跳过重复 / 读取失败”的统计。
- 旧版项目中的素材会在需要时补充视觉指纹，提高继续导入时的去重效果。

如果需要同一张照片在 A4 上出现多次，不要重新导入：

- 直接修改素材卡片里的 **数量**；
- 或在预览中选择图片后，用工具栏里的 **数量 −1 / +1** 调整副本数。

## 保留功能

- 打印 / 保存 PDF

- 手机预览多选模式
